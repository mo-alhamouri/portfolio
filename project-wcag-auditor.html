01 — Why it matters

Why use it?

Zero Noise: Smart filters ignore decorative layers and background shapes to keep your results actionable.

Contextual Zoom: Double-click any result to zoom directly to the layer on your canvas.

Built for Teams: Standardized reports make it easy to clear issues before handoff.

02 — Process

The Process

Building this plug-in involved a highly iterative and AI-assisted workflow. By leveraging advanced language models for both design logic and code generation, I was able to rapidly prototype, test, and refine complex accessibility auditing features.

01

AI-Driven Strategy & Refinement

Leveraging ChatGPT, I refined the instructions provided to the Gemini CLI AI model. This strategic approach focused on precise feature definition, efficient bug fixing, and overall enhancement, significantly reducing token consumption and optimizing the AI's performance for the project.

02

Terminal-Based Development with Claude

The refined instructions were then integrated into Claude within the terminal. This phase focused on building the core features and crafting the visual identity of the plug-in, ensuring the underlying codebase was robust and performed seamlessly.

03

Rigorous Figma Testing

Once the plug-in's user interface was live in Figma, I transitioned into a rigorous testing phase. Every feature was meticulously evaluated to ensure accurate implementation, optimal functionality, and a smooth user experience within the Figma environment.

04

Continuous Enhancement & Community Feedback

Development remains an ongoing process. I continuously leverage Claude for maintenance and feature updates, while actively incorporating feedback from the Figma Community to refine and enhance the plug-in's capabilities over time.

03 — Insights

Research, Options & Trade-offs

What research revealed

Designers ignored audit tools that flagged decorative layers and background shapes. Noise, not missing checks, was the main complaint.

Directions explored

  • Option A: Flag everything and let users filter. Dropped: too noisy.
  • Option B: Smart filters that skip decorative layers, plus double-click to zoom to the issue. Chosen.

Trade-offs

Figma plug-in API limits shaped which checks could run automatically. Some checks stay guidance rather than automatic detection.

Leadership · Making a hard call

Fewer results, but every one worth acting on

The easy version of this plug-in would have flagged everything and left designers to sort it out, and that is exactly the noise that made them ignore other audit tools. I chose smart filters that skip decorative layers and background shapes, and double-click to jump straight to each issue, so every result is something a designer can fix before handoff.

What it cost: Coverage. Checks the Figma plug-in API can't run reliably stay as guidance instead of automatic detection, so the tool does less on its own in exchange for results people trust.

05 — Features

Key Features

The WCAG Accessibility Auditor is packed with features designed to make accessibility audits fast, accurate, and actionable.

Master Audit

Run a comprehensive full-page scan. Contrast, targets, typos, and alt-text checked across all artboards in a single click.

Contrast Checker

Verify text-to-background ratios against WCAG AA (4.5:1) standards with instant zoom-to-layer functionality.

Smart Targets

Ensure your interactive elements are accessible. Toggle between Mobile (44px) and Desktop (24px) standards to match your platform.

Heuristic Typo Detection

Beyond a simple spellcheck. Detect "Lorem Ipsum" placeholders, keyboard slips (df, sa), double words, and inconsistent UI labels.

Identifiers Check

Automatically find status indicators and icons that rely purely on color to convey meaning—ensuring they include proper icons or text for color-blind users.

AI Alt-Text

Manage and generate descriptive alt-text for images and icons, ensuring your designs are accessible to screen reader users.
